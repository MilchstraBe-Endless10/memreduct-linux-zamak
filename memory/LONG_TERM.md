# 长期记忆 / Stable Contract — v1

**变更条件：** 只有用户确认重大需求/架构修改或已合并 ADR 才更新。此文件不是每日工作日志。

## 目标和体验
- Mem Reduct 风格的 Linux 原生“点击即执行内存管理”工具，不是任务管理器/磁盘清理工具；中文优先、美观、不依赖 Docker 或 WebUI。
- **UI/UX 硬约束：**唯一高保真基准为 Henry++ Mem Reduct `v.3.5.2`，tag SHA `2f5c55d15f69a2c88859e036b16c6f4c971e1968`。禁止自主重新设计、现代化、放大或简化原版布局；主窗和全部设置/对话框遵循各自官方资源尺寸，不做大窗口版；English 与简体中文必须独立切换。资源 Dialog Units 不是像素，需以真实字体/DPI转换。CI 的 336×348 窗口只供探针测试，不能成为产品尺寸。
- 原版字体校准只能使用可合法分发的系统字体替代；不得复制、打包或提交 Windows 专有字体。候选字体先在隔离 CI 进程做 GDI/Pango 字符度量与实际截图对照；只有英文、简中两种字形、文本度量和截图证据支持且几何不回退时才考虑生产采用。保留 CJK fallback。P2C-4 的 Liberation Sans 隔离测量虽改善多数英文宽度，但简中收益不稳定且全页差异改善很小，因此没有采用到生产 UI；不能仅凭单语宽度数据提升候选字体。字体栅格化与 GTK 原生控件差异需单独记录，不能混作几何误差或像素通过。
- 应用 Canvas 暗色调色板与 GTK 桌面主题是不同状态，测试必须分别记录；不得为视觉测试改动用户全局 GTK/Hyprland 主题。暗色截图只说明该应用模式有渲染变化，不能推导为 GTK 原生暗色主题或整体像素等价。
- 视觉验收保留真实 Windows/Linux 源图及 SHA-256；控件几何、文本/语言、字体栅格、原生控件绘制和安全禁用状态分别比较。每份报告须绑定明确源码 HEAD、Actions run、artifact digest 与 PNG SHA，不得跨 run 混用图片和指标。预期尺寸/状态要由当前原生截图或独立测量复核，不能让被测实现和比较器共用同一未经复核的常量；局部改善不等于全页像素等价。
- 图形验收必须分开报告 GTK/Wayland 客户端启动与退出、真实鼠标键盘输入、以及 compositor 自身的关闭状态。Weston Headless 客户端生命周期 PASS 不代表 Wayland 输入通过；若 runner 的 compositor 日志保留 teardown 警告或 BUG，必须披露并保留日志，不能因 Actions job 成功而称其正常关闭，也不能在缺少证据时归咎应用。
- 上游简体中文资源未翻译、但 Windows 中文运行时仍显示英文的项目，必须逐资源保留来源差异并标为待产品决策；不得为了截图一致而静默删除项目要求的简体中文支持，也不得把项目翻译说成原版原文。
- UI 高保真与 Windows 内存 API 等价是两条独立验收线。Linux 指标和清理动作必须逐项做语义/安全映射；不支持的操作不得伪装或统一接到 `drop_caches`。
- 目标环境 Arch / Omarchy + Hyprland (Wayland)；兼容其他发行版属后续增强，不得未经测试宣称支持。
- 免费开源；独立实现受 Henry++ Mem Reduct 启发，GPL-3.0-or-later，保持正确署名与第三方声明。
- 技术选型已确定：Zamak 0.2.x + Linux GTK3 `std/ui` + 尽可能少的 C 适配层。先使单端应用能够编译，再考虑更复杂 UI。

## 永久安全红线
- 禁止通过杀进程/暂停进程充当清理；程序不中断作为目标，但**不能保证没有延迟/CPU/I/O 影响**。
- 特权层单独运行，严格限制操作枚举与目标文件，不以 root 运行 GUI。所有系统写操作必须显式授权、记录退出状态。
- 不做无条件高频清理，不在用户机器上默默启用 swapoff/重配 ZRAM/cgroup reclaim；自动策略默认关闭且须有冷却和关闭开关。
- `drop_caches` 是调试级缓存驱逐能力，不是性能提升的证据；不自动套用风险高的优化参数。
- RAM 统计按来源拆分：MemTotal/MemAvailable、Cached、SReclaimable、Swap；释放量以**观测变化**表述。

## 工程与协作规则
- `AGENTS.md` 为入口；`docs/ADR/` 是正式决策；长期/中期/短期记忆不能互相覆盖。
- Codex 负责代码与实机验证；ChatGPT 负责复审、任务拆解；用户决定发布/合并及安全取舍。唯一主写入者原则。

## 非目标（当前）
- 不追求 1:1 Windows Native API 行为；不追求显示大量“已释放 GB”但实际只有统计数字波动。
- v0.x 不默认支持自动终止进程、任意内核参数调节、无提示的系统服务常驻。
